# The Kit improves through harvested Lessons and a Kit Loop, with human triage in between

Working on a Project surfaces Lessons for the Kit. A Harvest skill files each one as a GitHub issue on the Kit (label `needs-triage`) carrying: what happened, which Kit part it touches, the proposed change, and a link to the prompting Project commit or PR. The Kit's issue tracker is GitHub Issues rather than local markdown because Lessons originate in other repos' sessions. You triage; a Kit Loop then turns `ready-for-agent` issues into PRs under the ADR 0004 boundary (PR, never merge). Fully automatic triage was rejected because Lessons are raw and need judgment. Skills, Loops and Stack Rules reach existing Projects through the plugin; scaffolded code reaches them through the Sync Loop (ADR 0006).
